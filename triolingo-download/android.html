3 Bước cài đặt Triolingo APK trên điện thoại Android
1

Tải file triolingo.apk về máy

Bấm vào nút "TẢI XUỐNG FILE APK (10 MB)" ở trên. Điện thoại sẽ tải file triolingo.apk về máy trong vài giây.

2

Mở file & Cho phép cài đặt

Kéo thanh thông báo xuống hoặc vào thư mục Tải về (Downloads) để mở file vừa tải. Nếu máy hỏi bảo mật, bật "Cho phép cài đặt từ nguồn này" (Allow from this source).

3

Nhấn "Cài đặt" (Install) để hoàn tất

Nhấn nút Cài đặt. Quá trình diễn ra tự động trong khoảng 3 giây. Biểu tượng Triolingo sẽ hiển thị trên màn hình chính điện thoại, mở lên học ngay!

Hoặc học nhanh qua Chrome (Không cần cài APK)

Bạn cũng có thể mở trình duyệt Chrome trên điện thoại, truy cập https://triolingo-web.vercel.app, nhấn nút 3 chấm góc phải và chọn "Thêm vào màn hình chính" để học toàn màn hình.
